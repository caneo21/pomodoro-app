# 안드로이드 포모도로 앱 설계

- 작성일: 2026-08-11
- 상태: 승인됨 (구현 계획 수립 단계로 전환)

## 배경 / 목표

안드로이드 OS 스마트폰에서 동작하는 포모도로 타이머 앱을 만든다. 사용자는 프로그래밍 경험은 있으나 안드로이드/모바일 개발은 처음이며, 이 앱은 iOS 지원이 필요 없는 안드로이드 전용 앱이다. 범위는 최소 기능(핵심 타이머 + 알림)으로 시작하고, 추후 통계/자동 전환 등은 별도 확장으로 미룬다.

## 기술 스택

- 언어: Kotlin
- UI: Jetpack Compose
- 아키텍처 패턴: MVVM
- 로컬 저장소: Jetpack DataStore (Preferences) — 집중/휴식 시간 설정값 영속화
- 최소 지원 버전: minSdk 26 (Android 8.0), targetSdk 최신 안정 버전

선정 이유: 사용자가 안드로이드/모바일 개발 경험이 없고, 이 앱은 안드로이드 전용이라 크로스플랫폼(Flutter/React Native)의 이점(iOS 동시 지원)이 필요 없다. 네이티브 스택이 공식 문서·자료가 가장 풍부하여 학습 곡선 대비 유리하다.

## 아키텍처

- **TimerViewModel**: UI 상태를 `StateFlow`로 노출. Compose UI가 구독.
- **TimerService** (Foreground Service): 실제 카운트다운을 수행하는 진실의 원천(source of truth). 앱이 백그라운드로 가거나 화면이 꺼져도 서비스가 살아있는 동안 정확하게 동작한다.
- **Activity ↔ Service 통신**: `MainActivity`는 화면이 보일 때 `TimerService`에 바인딩하여 서비스가 보유한 `StateFlow`를 구독한다. 바인딩이 해제되어도(앱이 백그라운드로 가도) 서비스는 `startForeground()` 상태로 카운트다운을 계속한다.

타이머 구현 방식으로 Foreground Service를 채택한 이유: 단순 ViewModel 코루틴 타이머(대안 B)나 AlarmManager/WorkManager 조합(대안 C)은 각각 "앱이 오래 백그라운드에 있을 때 타이머가 죽거나 부정확해짐" 또는 "실시간 초 단위 UI 갱신에 부적합"이라는 문제가 있다. 포모도로 앱은 "화면을 보지 않아도 정확히 울려야 한다"는 요구가 핵심이므로 Foreground Service를 사용한다.

### 정확성 보장

`CountDownTimer` 단독 사용은 시스템 스로틀링 등으로 드리프트가 발생할 수 있다. 대신 세션 "종료 시각"(`System.currentTimeMillis() + 남은ms`)을 기준으로 매 tick마다 남은 시간을 재계산하여, 표시되는 시간이 실제 경과 시간과 어긋나지 않도록 한다.

## 화면 구성

### ① 메인 타이머 화면
- 원형(또는 프로그레스 바) 형태로 남은 시간을 mm:ss로 표시
- 현재 모드 표시: "집중" / "휴식"
- 컨트롤: 시작 / 일시정지 / 리셋 버튼
- 설정 화면 진입 아이콘

### ② 설정 화면
- 집중 시간 조정 (분 단위, 5~60분 범위)
- 휴식 시간 조정 (분 단위, 1~30분 범위)
- 저장 시 DataStore에 영속화, 메인 화면으로 복귀

범위 제외: 세션 기록/통계, 4회마다 긴 휴식 등 뽀모도로 기법의 세부 규칙, 사운드/테마 커스터마이징. 최소 기능으로 시작 후 필요 시 확장.

## 세션 전환 로직

1. 사용자가 "시작"을 누르면 `TimerService`가 시작되고 집중 세션 카운트다운이 개시된다.
2. 집중 세션이 종료되면 알림음+진동을 울리고, 자동으로 휴식 세션으로 전환되어 카운트다운이 계속된다.
3. 휴식 세션 종료 시에도 동일하게 알림 후 다시 집중 세션으로 전환된다.
4. 사용자는 언제든 일시정지/리셋을 통해 서비스에 명령을 전달할 수 있다.

집중↔휴식은 단순 반복이며, 4회마다 긴 휴식 같은 규칙은 이번 범위에 포함하지 않는다.

## 알림 (Notification)

- **진행 중 알림**(ongoing, 스와이프로 제거 불가): 예) "🍅 집중 중 · 12:34 남음". 탭하면 앱으로 복귀하고, 일시정지 액션 버튼을 포함한다.
- **세션 종료 알림**: 별도로 소리+진동을 동반한 알림을 발생시킨다 (예: "휴식 시간입니다!" / "다시 집중할 시간입니다!").
- Android 13+(API 33)에서는 최초 실행 시 `POST_NOTIFICATIONS` 권한을 요청해야 한다.

## 테스트 계획

- `TimerService`의 카운트다운/세션 전환 로직은 순수 로직으로 분리하여 JUnit 유닛 테스트로 검증한다.
- `TimerViewModel`의 상태 매핑 로직을 유닛 테스트로 검증한다.
- 시작/일시정지/리셋 버튼 동작을 Compose UI 테스트로 검증한다.
- 수동 테스트: 화면을 끄고 일정 시간 방치한 뒤 정확한 남은 시간을 표시하는지 확인하고, 앱을 다른 앱으로 전환한 뒤 세션 종료 알림이 정상적으로 오는지 확인한다.

## 향후 확장 후보 (이번 범위 아님)

- 작업/세션 기록 통계
- 4회마다 긴 휴식 등 포모도로 기법 세부 규칙 자동화
- 커스텀 알림음/테마
